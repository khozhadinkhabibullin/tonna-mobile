# Изображение маршрута в 2ГИС

## Вывод

Да. Static API возвращает PNG карты с маркерами А/Б и линией маршрута. Для этого не нужен интерактивный JavaScript SDK. Это документированный API для изображения, а не извлечение картинки из страницы шеринга.

Static API не рассчитывает путь по дорогам. Для такого изображения нужны два шага:

1. Routing API рассчитывает маршрут и возвращает геометрию.
2. Static API рисует геометрию и маркеры на карте.

Для работы нужны API-ключ и доступ к соответствующим сервисам. Публичная ссылка на маршрут в 2ГИС не заменяет эти API.

## API и ограничения

- Актуальный Routing API использует `POST https://routing.api.2gis.com/routing/7.0.0/global?key=API_KEY`. Запрос с `output: "detailed"` возвращает геометрию сегментов в WKT.
- Грузовые маршруты доступны в Казахстане и Кыргызстане. Можно учитывать массу, размеры машины и тип груза. Обычный автомобильный маршрут нельзя выдавать за проверенный грузовой.
- Для пробного ключа Routing API документация указывает максимальное расстояние между точками 50 км. Он не подходит для проверки полного маршрута Алматы → Караганда.
- Static API: `GET https://static.maps.2gis.com/2.0?...&key=API_KEY`, ответ PNG. Размер от 120×90 до 1280×1280, модификатор `@2x` для Retina/HiDPI.
- Параметр `ls` рисует ломаную. `pt` добавляет маркеры, `g` принимает GeoJSON. Если есть объекты, центр и масштаб можно не задавать: карта подстроится автоматически.
- Порядок координат отличается: `pt` и `ls` используют **широту, долготу**, GeoJSON, WKT и ссылки на маршрут используют **долготу, широту**. Конверсию нужно проверить тестом.
- Прямая между двумя городами не является рассчитанным маршрутом. Для линии по дорогам нужно передать геометрию всех необходимых сегментов.

Пример формата URL. Координаты должны быть взяты из рассчитанного маршрута, это не готовый запрос:

```text
https://static.maps.2gis.com/2.0?s=400x220@2x&pt=LAT_A,LON_A~n:1&pt=LAT_B,LON_B~n:2&ls=LAT_A,LON_A,...,LAT_B,LON_B~w:4~c:ff5c19&key=API_KEY
```

Тариф, лимиты, разрешённое хранение изображений и ограничения длины URL необходимо уточнить перед интеграцией. Для длинного межгородского маршрута нельзя предполагать, что вся геометрия поместится в один URL без упрощения.

## Переход в приложение

Официальная справка описывает ссылки вида:

```text
https://2gis.ru/directions/tab/truck/points/LON_A,LAT_A|LON_B,LAT_B
```

Город в URL необязателен. Идентификатор организации можно опустить, координаты конечной точки обязательны. Обе точки должны соответствовать открытому заказу. Если координаты ещё не определены, нельзя отправлять пользователя на маршрут другого заказа.

## Что делать в макете

Показывать честную схему А → Б без движущегося грузовика, процентов и заявления о текущем местоположении. Дать переход в 2ГИС для заказов с известными координатами. Реальную статическую карту подключать после получения ключа и проверки грузового маршрута.

Макет не отправляет адреса, координаты или профильные данные в API. Переход по внешней ссылке выполняется только по нажатию пользователя.
